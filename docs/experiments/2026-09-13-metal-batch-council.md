# Alternatives and trade-offs

1. **Batch epoch 5 first, recommended.** Sharing immutable graph storage and processing independent trajectories per dispatch may amortize overhead and improve GPU utilization. These are testable throughput hypotheses. This route preserves the completed experiment as a comparison and leaves its cancellation defects visible.
2. **Batch epoch 6 first.** This preserves corrected local carry semantics, but introduces substantially worse observed trajectory agreement relative to CPU. It is defensible as separately declared dynamics; the stronger regression complicates interpreting the next experiment. Reconsider after targeted diagnostics establish the consequences of the correction.
3. **Recover CPU event ordering first.** Reconstruct queue/source order, original outgoing-edge order and per-edge modulation. This prioritizes numerical-reference fidelity, with unmeasured implementation and performance costs. It has no demonstrated learning benefit and need not block the bounded batch executor. The existing CPU multi-trajectory executor remains available for matched cohorts and reference measurements, subject to available resources.

Share only immutable graph/incoming topology. Every lane owns mutable efficacies, neural state, delayed queues/bitmaps, plastic traces/memory, reinforcement history and decoder state. Retain MaleCNS v1.0's 166,700 neurons and all 25,582,938 edges, including duplicates, weak, self and modulatory edges. Preserve dt 0.1 ms, host float64 plasticity, all 4,184 KC-to-MBON11 slots, the 50 ms filter, fixed decoding and current Metal/compiler portability constraints.

Before N=4, require:

- N=1 compatibility with serial epoch 5; **every N=2 lane** bitwise identical to its own serial run for neural state, spikes, delayed state, traces, efficacies and decoded controls. Exercise different RGB inputs and both frozen and plastic trajectories.
- Deterministic repeats; lane permutations reproduce the corresponding serial results; changing one lane's input, initial state or reinforcement leaves the other lane's complete result unchanged. Check host plasticity scheduling as well as GPU indexing.
- Unchanged short CPU gates, epoch-5 two-second dark parity, retained graph/nonplastic invariants and reproducible historical failures. Known failures remain explicitly recorded; newly introduced identity or gate failures stop scaling until corrected.

Benchmark matched **complete RGB workloads**, including host plasticity and transfers, using identical frames, durations, arms and synchronization boundaries. Report warmup separately, aggregate RGB brain-seconds/wall-second, per-lane latency, memory, run-to-run variability and profiling overhead. Compare serial Metal, batched Metal and CPU with explicit concurrency. The existing eight-phase walls are 1,516.26 s Metal versus 968.55 s CPU; short contiguous benchmarks cannot substitute for this measurement.

After correctness passes, test N=4 if memory permits and repeat all lane checks. Treat reproducible aggregate improvement beyond measurement noise as evidence for further scaling. If improvement is absent, stop increasing lane count and profile/refine Metal. No speed percentage is a scientific gate or a measured forecast.

Add optional event-level diagnostics around epoch 5's actual RGB divergence and epoch 6's first-turn/dark windows: queue/source/edge ranks, incoming contributions, pre/post conductance, modulation decay/add and threshold crossings. Ten-millisecond summaries locate a window; finer traces locate the first differing operation. Diagnostic contribution replay should vary ordering and modulation association separately. Confirm probes preserve outputs and measure their overhead; observed correlation alone cannot assign full-network causality.

Dispatch, gathering, settlement, synchronization and host plasticity remain candidate bottlenecks; the 97% backend fraction was measured on CPU. No timing breakdown proves dispatch dominance or rules out the aspirational 1000x target. Aggregate throughput also does not establish one live game's acceleration. Ordering/modulation causality, bilateral PPL101 pooling physiology and effective credit assignment remain unresolved.
